next to its sources.

## Local changes

- `third_party/cva6/core/cva6.sv`: the `instr_tracer` instance is guarded by
  `` `ifdef CVA6_INSTR_TRACER `` instead of `` `ifndef VERILATOR ``. See
  [docs/VIVADO_NOTES.md](docs/VIVADO_NOTES.md).
- `rtl/cpu/ibex/ibex_axi_top_combined.sv`: the `BUFGCE` `SIM_DEVICE` parameter follows the
  part (`ULTRASCALE_PLUS` when `CORE_SOC_ULTRASCALE` is defined, `7SERIES` otherwise).

All other third-party files are unchanged copies of the versions above.
